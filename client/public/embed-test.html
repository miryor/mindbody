Mindbody Widgets - Embedding Test

This page demonstrates how to embed and use Mindbody widgets on your website. There are multiple ways to embed widgets:

Example 1: Manual Initialization

Manually initialize the widget library and render a specific widget:

// Initialize the library with a specific version
MindbodyWidgets.init({
  baseUrl: 'http://localhost:3000',
  debug: true,
  version: '0.1.0'  // Use versioned UMD file
});

// Render a widget
MindbodyWidgets.render('HelloWorld', {
  targetElementId: 'widget-example-1'
});

Example 2: Auto-Initialization with Data Attributes

Use data attributes to automatically initialize and render widgets:

<div id="widget-example-2" 
  data-mindbody-widget="HelloWorld" 
  data-widget-theme="light"
  data-widget-studioId="12345"></div>

Note: Auto-initialization requires the embedding script to have the data-mindbody-widgets-auto-init attribute.
